Title: Automated rotate-until-target-detected using episodic memory analysis

Goal
Rotate the robot right in discrete steps until an image analyzer confirms the target is visible, with no human-in-the-loop.

Prerequisites
- Stimulus description (e.g., “red bag”) and any visual attributes.
- Robot controller initialized; camera and movement commands responsive.

Steps
1) Create a dedicated episodic memory folder: rotate_until_<target>_<timestamp>. In guide.txt, describe the target and task.
2) Readiness probe: capture_robot_image once. If it errors (e.g., not initialized), stop and request user to start the controller.
3) For step i in [1 .. MAX_STEPS] (≈24 for full 360°):
   a. capture_robot_image
   b. Promote the latest working capture into episodic/images as frame_{i:02d}.jpg (use a helper script to copy from working to episodic)
   c. analyze_memory_image on that frame with a yes/no question about target presence
   d. If analyzer says yes: stop_robot_motion (safety) and end success, noting i and approx angle
   e. Else: turn_robot_right (discrete default), then continue
4) If MAX_STEPS exhausted: report not found; consider adjusting step size, moving position, or refining target description.

Notes
- Use discrete turns and capture after the turn completes to avoid motion blur.
- Keep a simple per-frame log in the episodic memory guide.
- If orchestration has low max-iterations, run the loop in chunks or request higher limits.

Safety
- Be ready to issue stop_robot_motion if any unexpected continuous motion occurs.
- Keep movement small and controlled; verify environment if obstacles are suspected.
