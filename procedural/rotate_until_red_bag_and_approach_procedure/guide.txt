Title: Rotate-until-red-bag and short approach (procedure)

Purpose
- Find a predominantly red bag (handbag, tote, backpack, grocery bag) using stepwise rotation and capture.
- Optionally approach the detected bag in small, safe increments.

Pre-checks
- Ensure area is clear of obstacles; confirm manual stop command is available.
- Initialize counters: step_index = 0; max_steps = 24 (approx full 360° with 15° increments).
- Prepare logging: create a run folder; plan to save baseline, each frame, and annotated detection.

Detection criteria
- Predominantly red region with bag-like contour/shape.
- Ignore tiny red specks or large flat red surfaces unrelated to a bag.

Procedure
1) Baseline
   - Capture and save a baseline frame (no bag expected). Name: baseline.jpg.
2) Rotate until detected
   - Loop until step_index == max_steps:
     a) Turn right one increment (≈15°) and auto-stop.
     b) Capture a new frame; save as frame_{step_index:02d}.jpg.
     c) Analyze frame for red-bag presence.
     d) If detected: save annotated image (annotated_step_{step_index:02d}.jpg) and break.
3) Optional centering
   - If detection is off-center, apply small left/right turns, recapture, and re-evaluate until centered.
4) Short approach
   - Move forward in 1–2 small increments; recapture after each move.
   - Monitor apparent area ratio growth. Stop if growth indicates too-close approach or if object leaves frame.
5) Logging and wrap-up
   - Save final capture (latest_capture.jpg) and a brief run summary (run_summary.txt).

Safety and fail cases
- If not found after max_steps, report not found, stop motion.
- Use stop command to halt continuous motion if needed.

Notes
- When image attachment into long-term memory is available, include: baseline.jpg, annotated detection, and final approach frame.
