Title: Rotate-Until-Target-Detected Loop (Vision-in-the-loop)

Use case: Turn the robot in steps and keep checking the camera until a visual target (e.g., dog) is detected.

Prerequisites:
- A vision-analysis tool that can return True/False for “target detected” given the latest camera image, or a human-in-the-loop to confirm visibility.
- Robot movement and camera capture tools available.

Procedure:
1) Initialize
   - Set max_steps (e.g., 24 for ~360° if 15° turns).
   - Set turn_step to default (one right-turn step = ~15°) unless specified otherwise.
2) Loop per step i in [1..max_steps]:
   a) Capture an image: functions.capture_robot_image
   b) Analyze image for target:
      - If automated: call vision tool; if detected → stop.
      - If human-in-the-loop: present image or ask user if target is visible; if yes → stop.
   c) If not detected, turn robot right one step: functions.turn_robot_right
   d) Optionally, brief pause to stabilize, then continue.
3) If max_steps reached without detection:
   - Report not found within one full rotation; request guidance.
4) Safety:
   - Be ready to call stop_robot_motion if continuous commands are used.
   - Keep steps discrete to avoid drifting.
5) Reporting:
   - Only report actions actually executed via tools (movement, capture, analysis). Avoid claiming actions not taken.

Notes:
- For targets expected off to one side, start by turning toward that side.
- Consider adaptive step sizes: larger turns initially, smaller once near detection.
- Log timestamps and step indices for traceability.
