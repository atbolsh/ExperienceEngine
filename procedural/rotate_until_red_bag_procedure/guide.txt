Title: Rotate until Red Bag Detected (Autonomous)

Goal:
- Rotate the robot in place in small steps, capturing an image each step, and stop as soon as a prominent red bag comes into view.

Detection definition:
- Target is a predominantly red bag-like object (handbag / tote / backpack / grocery bag). Use color dominance (red in HSV) and coarse shape/size cues (sizable contour; plausible rectangular bounding box; moderate aspect ratio). Ignore tiny red specks, LEDs, flat wall posters, or very distant pixels.

Safety constraints:
- Use discrete turns (default turn step ~15°). Max steps for a sweep: 30 (approx. 450° cap) to avoid infinite loops.
- Capture a baseline image before any motion.
- At any point, if detection is positive, stop motion immediately.

Procedure:
1) Baseline: Capture a robot image. Run red bag detection on it. If detected, report success and stop.
2) Sweep loop:
   - For step i in [1..30]:
     a) Turn right one default step.
     b) Capture a robot image.
     c) Run red bag detection on the new image.
     d) If detected, stop and report success with the step index and an annotated image.
3) If not detected after max steps, report not found after full sweep.

Outputs to report:
- Detected: true/false
- Step index (bearing approx = step_index * 15°)
- Bounding box [x, y, w, h]
- Area ratio and confidence score
- Path to annotated image with bounding box overlay (if available)

Notes:
- After session, record an episodic memory with the outcome and any surprises.
- If detection tool is missing, first create/load it, then run this procedure.
