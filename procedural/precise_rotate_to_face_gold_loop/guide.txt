Goal: Face the nearest gold using tight perception–action.

Procedure:
1) Capture: analyze_current_game_view with question: “Relative to my current facing, is the NEAREST gold left, right, centered, or behind? Answer with one letter: L/R/C/B.”
2) Decision:
   - If L: turn_game_counterclockwise once.
   - If R: turn_game_clockwise once.
   - If B: turn_game_clockwise 15 times (≈90°) and go to step 1.
   - If C: perform a second confirm—reanalyze with same question.
3) Confirm:
   - If C again: stop rotating (now facing gold).
   - If L/R/B: resume step 2 accordingly.
4) Notes:
   - After each turn, re-run analyze_current_game_view.
   - Avoid chaining more than 2 actions without a check.
   - Save a snapshot when alignment is confirmed.

This minimizes misinterpretation and drift by using single-letter responses and single-step turns.
