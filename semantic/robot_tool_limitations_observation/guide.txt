Robot tools summary (as of 2025-11-17):
- Available: capture_robot_image; move_robot_forward; move_robot_backward; turn_robot_left/right; stop_robot_motion.
- Not available: automated computer vision classification on working camera images (e.g., dog detection). Requires custom tool implementation and session restart to load.
- Best practice: When autonomy requires perception (e.g., detect a dog), either (a) human-in-the-loop confirmation after each capture, or (b) implement a dedicated vision-analysis tool before starting the task.
- Reporting guideline: Only report actions that were actually executed via the provided tools; do not infer or claim movement without tool calls.
